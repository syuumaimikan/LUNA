# sounds/

`mascot.json` が参照する効果音。**未配置でもパックは動作する**（音が鳴らないだけ）。

| ファイル | 使われる場所 | 目安 |
|---------|-------------|------|
| `step.ogg` | `walk` のフレーム 0 / 2 | ごく短い足音。音量 0.25 で再生される |
| `siren.ogg` | アラーム「おおごと」 | 1〜2 秒。ループはエンジン側では行わない |

制約（検証 V11）:

- 形式は `.ogg` または `.wav`
- 1 本あたり **512KB 以下**
- パックルート配下に置くこと（`..` や絶対パスは拒否される）

静音モードでは全ての音が鳴らない。足音は「静か」寄りに作り、鳴り続けても気にならない音量にする。
