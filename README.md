# LUNA

Windows 向けデスクトップマスコット。デスクトップの片隅にチビキャラ「ルナ」が住みつき、
**デスクトップを地形として歩き回り**、なでると反応し、**PC の状況に反応**する。

> 現在のステータス: **実装中**。
> 設計とキャラクターパック仕様は完成。振る舞い・地形・物理・ジェスチャ・
> 親密度・タイマー・リアクションの中核ロジックは実装済みで、
> **316 件のテストが通っている**（`npm run check`）。
> 未着手は Electron のウィンドウ、PixiJS 描画、koffi によるウィンドウ列挙、
> 設定 UI、スプライト作画。詳細は [ROADMAP](docs/ROADMAP.md)。

---

## これは何か

- 手のひらサイズの 2D チビキャラがデスクトップに常駐する
- **デスクトップを地形として扱う** — 画面の下端を歩き、ウィンドウの側面を登り、タイトルバーの上に座り、下端にぶら下がり、ときどき意味もなく飛び降りる
- **なでる・つかむ・ふる・投げる** — マウスで頭を撫でると3段階で反応が変わる
- **一緒に過ごすほど親しくなる** — 日数となでた回数で 6 段階、セリフが増えていく
- **ポモドーロとアラーム** — 作業中は静かに、休憩には確実に割り込み、アラームは床を走り回って知らせる
- **PC の状況に反応する** — CPU が唸れば汗をかき、バッテリーが減れば充電を促し、深夜にはあくびをする
- キャラは **JSON + PNG の「パック」**として差し替え・追加できる（コード不要）

### 設計の三原則

| | |
|---|---|
| **邪魔をしない** | フォーカスを奪わない。クリックを吸わない。全画面アプリの上に出ない。喋りすぎない。 |
| **生きている** | ランダムではなく文脈で動く。 |
| **拡張できる** | キャラはデータ。コードを書かずに増やせる。 |

### 参照作品

[**Little LUMI Model**](https://store.steampowered.com/app/5075020/Little_LUMI_Model/)（Steam / 2D 手描き / 64 挙動・122 フレーム）を参照点としている。
「デスクトップを地形として扱う」「なでる」「一緒に過ごすほど親しくなる」の三点を体験の芯と捉え、
そこに **PC 状況連動**という独自要素を足す構成。踏襲した点と変えた点は [DESIGN.md §1.1](docs/DESIGN.md#11-参照作品) にまとめてある。

## プライバシー

地形（ウィンドウの縁）を作るために、可視ウィンドウの位置と大きさを列挙する。
**矩形とウィンドウハンドル以外は保持しない。** ウィンドウのタイトルは取得しても即破棄し、ログにも残さない。

アプリ本体は**既定で一切通信しない**。センサー値もだいすき度も、この PC の中で完結する。
詳細は [DESIGN.md §16](docs/DESIGN.md#16-セキュリティとプライバシー)。

## リポジトリ構成

```
LUNA/
├─ docs/          設計ドキュメント
├─ packs/luna/    既定キャラ
│  ├─ mascot.json    35アニメ / 8状態 / 17リアクション（完成）
│  ├─ dialogue/      15キー / 45行、だいすき度で段階解禁（完成）
│  ├─ sprites/       87フレームの一覧と作画ガイド（画像は M1–M2 で作成）
│  └─ sounds/        足音・サイレン（M2 以降）
├─ scripts/
│  └─ check-docs.py  内部リンクとパック整合性の検査
├─ src/
│  ├─ shared/     Clock/Rng の抽象、幾何・アクター・パックの型、IPC 契約
│  ├─ main/       地形生成・センサー正規化・リアクション・親密度・タイマー・パック検証
│  └─ renderer/   物理・接着移動・状態機械・ジェスチャ認識・ドラッグ
└─ tests/         単体 + 結合（316 件）
```

```bash
npm install        # ELECTRON_SKIP_BINARY_DOWNLOAD=1 でも中核テストは全て動く
npm run check      # typecheck + lint + test + ドキュメント/パック整合性
```

ドキュメントとパックの整合性は `python3 scripts/check-docs.py` で検査できる
（内部リンクの解決、アニメ・セリフ・状態の相互参照、シグナル名、検証 V3–V14 のうち静的に効くもの）。
